سایت تالیفی (استاتیک) یعنی چی؟ و چرا برای دیجی‌فیر خوبه؟

سایت تالیفی (Static Site Generation - SSG) یعنی صفحات HTML از قبل (build time) ساخته می‌شن، نه در لحظه درخواست. مثلا همین ۵ صفحه بهبود یافته شما (home, about, contact, exhibitions, product) + ۱۴۷ Offer + ۲۴ ماژول — می‌تونیم همه‌شون رو به صورت استاتیک HTML بسازیم و روی Vercel / Render / Cloudflare Pages بندازیم. معنی SSG: سرعت فوق بالا (TTFB ~25ms Edge)، امنیت بالا (بدون PHP/MySQL مستقیم)، هزینه صفر، و سئو عالی چون HTML آماده‌ست. برای دیجی‌فیر که استایل دیجی‌کالا داره و زبان پیش‌فرض فارسی fa-IR، SSG عالیه چون Wagtail و ...

SSG چیست؟

در زمان build، همه صفحات به HTML استاتیک تبدیل می‌شن (مثل همین index-copyright-safe.html 18KB) - بدون نیاز به Node/Python در runtime برای فرانت - فقط API ها داینامیک می‌مونن

چرا برای دیجی‌فیر خوبه؟

چون ۱۴۷ Offer و ۵ صفحه اصلی ثابت هستن - هر بار محتوا عوض شد (مثلا نمایشگاه جدید)، build جدید می‌گیری - سرعت Edge + سئو فارسی عالی
